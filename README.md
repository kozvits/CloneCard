# CloneCard

Android-приложение для клонирования MIFARE Classic (13.56 МГц) карт через NFC телефона.

## Возможности

- **Чтение** — полное чтение MIFARE Classic 1K карты (UID + все 64 блока)
- **Запись** — запись дампа на целевую карту (включая UID на Magic Card)
- **Клонирование** — пошаговый мастер: чтение оригинала → запись клона → верификация
- **Сравнение** — карта vs карта, карта vs дамп, дамп vs дамп
- **Дампы** — управление сохранёнными дампами (импорт/экспорт в JSON)
- **Настройки** — управление ключами аутентификации, режимы записи

## Технологии

- **Kotlin** + **Jetpack Compose** (Material 3)

## Технические детали

Приложение работает с **Android NFC** (чип PN544/NQ210/STM). Для записи карт необходимо устройство с аппаратным NFC.

### MIFARE Classic

| Тип | UID | Запись UID |
|-----|-----|-----------|
| Оригинал NXP | 4-байт, фиксированный | ❌ Невозможно |
| Magic Card Gen1 | 4-байт, перезаписываемый | ✅ Через `writeBlock(0)` |
| Magic Card Gen2 | 4-байт, с подписью `bcdefghi` | ⚠️ Требует PN532 escape |
| U-UID / CUID | 4-байт, перезаписываемый | ✅ Напрямую |

### Ключи аутентификации

По умолчанию: `FF FF FF FF FF FF`, `00 00 00 00 00 00`, `A0 A1 A2 A3 A4 A5`, `D3 F7 D3 F7 D3 F7`.
